ComParta roadmap

First goal: a file shared from a PC can be downloaded from anywhere, with ComParta or with any other BitTorrent app, on Windows computers and Android phones, and nobody changes a router or opens a port.

53 of 111 stories are done. The written plan is in roadmap-comparta.md next to this page; the spec, architecture and epics sit beside it in Planning/initiative-comparta.

How a file reaches any app

On 13 Oct both ComParta's port (54759) and qBittorrent's port (3225) timed out when tested from outside Bruno's home, and a phone on 4G can never receive connections. When both sides can only connect out, they never meet. A helper that everyone can reach fixes that, and every app already knows how to use it.

Today: both sides closed

With the helper (epic 16)

Every arrow starts on the side that connects out, which always works. The copied link names the helper first, so any app finds it.

What we measure ourselves against

qBittorrent

Works with every other BitTorrent app and opens any public link. Details, pause, speeds. Its power-user screens stay out of the main view.

Stremio

Media first, on Windows and Android with the same feel. Proposed: a video plays while it is still arriving (needs Bruno's yes).

Google Drive

The look: a grid or list, a details panel, search and sort, sharing by copying a link, and later "Shared with me".
